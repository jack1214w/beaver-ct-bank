# 河狸運算思維挑戰 Beaver CT Bank

給國小中高年級（資優班）的運算思維體驗題庫，題型參考國際運算思維挑戰賽（Bebras）的風格。題庫共 **50 題**，分成 10 種解題能力，每次挑戰 10 題、每種能力各 1 題。答對一題，河狸的水壩就多一根木頭。

**線上使用**：https://jack1214w.github.io/beaver-ct-bank/

**教師手冊**：https://jack1214w.github.io/beaver-ct-bank/teacher-guide.html
50 題的答案、解題步驟、圖解、常見錯誤，以及學生卡住時可以問的三層提問。可以用瀏覽器列印成 PDF。

---

## 題庫結構

題號＝類別字母＋兩位數。**01、02 是 ★ 簡單，03、04 是 ★★ 中等，05 是 ★★★ 挑戰**。

| 類別 | 能力 | 類別 | 能力 |
|---|---|---|---|
| A | 排隊與堆疊 | F | 規律與樣式 |
| B | 編碼與二進位 | G | 最佳方案 |
| C | 地圖與路線 | H | 偵錯與密碼 |
| D | 圖片與壓縮 | I | 程式與指令 |
| E | 邏輯推理 | J | 搜尋與排序 |

## 學生可以選的題組

| 題組 | 題目 | 直接進入的網址 |
|---|---|---|
| 簡單題組 | A01～J01 | `…/beaver-ct-bank/#easy` |
| 中等題組 | A03～J03 | `…/beaver-ct-bank/#medium` |
| 挑戰題組 | A05～J05 | `…/beaver-ct-bank/#hard` |
| 隨機抽題 | 每類隨機 1 題 | `…/beaver-ct-bank/#random` |
| 自訂 | 任意題號 | `…/beaver-ct-bank/#A02-B04-C01` |

計分：第一次答對 10 分，再試一次答對 5 分，連錯兩次可以看解答但不得分。

## 讓全班寫同一組（class-set.json）

1. 打開網頁最下方的「教師後台」，輸入密碼。
2. 在「發布給全班」選好題組（可勾選「學生只能寫這一組」），按「產生全班題組設定」。
3. 按「複製」，再點連結打開 GitHub 上的 `class-set.json`，全選後貼上，按 **Commit changes**。
4. 大約 1 分鐘後，學生重新整理網頁，首頁最上方就會出現「老師指定的題組」。

要結束時按「產生『取消發布』設定」，同樣存到 `class-set.json`（內容是 `null`）。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 網站本體，可直接下載雙擊開啟 |
| `河狸運算思維挑戰.html` | 題庫原始檔（也用來發布到 Claude）；改這個檔，再執行 `sh build.sh` 產生 `index.html` |
| `teacher-guide.html` | 教師手冊網頁 |
| `教師手冊.html` | 教師手冊原始檔；改這個檔，再執行 `sh build.sh` 產生 `teacher-guide.html` |
| `class-set.json` | 全班指定題組，`null` 表示沒有 |
| `build.sh` | 把兩個原始檔包成 `index.html` 和 `teacher-guide.html` |

## 注意

- 這是公開的儲存庫，題目答案寫在網頁程式裡，懂得看原始碼的人看得到。教師後台的密碼只是擋在畫面上，不是真正的加密。教師手冊也是公開網頁，題庫首頁沒有放它的連結，但知道網址的人都能打開。
- 單一 HTML 檔，不需要伺服器；只有字型會連 Google Fonts，離線時自動改用系統字型。直接雙擊開啟時讀不到 `class-set.json`，其他功能都正常。
